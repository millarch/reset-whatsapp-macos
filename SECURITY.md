# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Do not open a public issue with vulnerability details or personal data.

Use **Security › Advisories › Report a vulnerability** in this repository to send a private report. Include:

- the affected version;
- minimal reproduction steps;
- expected impact; and
- a suggested fix, if available.

Do not attach chats, local databases, account identifiers, or other real WhatsApp data. Use fictional examples whenever possible.
